# That's My Font

> An iPad app that turns your handwriting into an installable OpenType font.

Draw letters with Apple Pencil or a finger, refine individual characters, preview the result in words, and export OTF files. Font creation happens on the device.

## Main Features

- Uppercase, lowercase, and number drawing
- Character size, position, and alignment controls
- Optional stroke smoothing
- Text preview before export
- Regular, Light, and Bold OTF export options
- No account and no handwriting uploads
