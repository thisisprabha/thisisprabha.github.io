# Tamil Typo

> An iPad app that turns hand-drawn Tamil characters into an installable OpenType font.

Draw Tamil characters with Apple Pencil, refine each glyph, preview Tamil words, and export OTF files. Font creation happens on the device.

## Main Features

- Tamil-aware character workspace
- Apple Pencil drawing and optional smoothing
- Glyph size, position, and alignment controls
- Tamil text preview
- Regular, Light, and Bold OTF export options
- No account and no handwriting uploads
